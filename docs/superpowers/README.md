# Original design and plans

These are Baton's original design (`specs/`) and implementation plans (`plans/`), written in
October 2026 with the [superpowers](https://github.com/obra/superpowers) plugin's `brainstorming`
and `writing-plans` skills (see [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)).

They are kept as history and are not updated. Where they disagree with the skills, `README.md` or
the code, the skills and the code are right. Plans for single issues now live in `refs/plans/<N>`,
linked from each issue's first line.
